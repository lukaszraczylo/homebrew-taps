Homebrew tap for the command-line tools at raczylo.com

Prebuilt binaries for macOS and Linux, on arm64 and amd64. Tap once, then install any project below as a cask. 

brew tap lukaszraczylo/taps

Install

Install a project by name. Homebrew taps the repository on first use.

brew install --cask lukaszraczylo/taps/<name>

Or declare the tap in a Brewfile:

tap "lukaszraczylo/taps"

cask "harness-sync"
cask "kportal"
cask "lolcathost"
cask "mcp-filepuff"
cask "readitall"
cask "semver-generator"
